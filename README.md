# AI Student Study Assistant

An AI-powered web application that helps students learn easily.

## Features
- Generate study summaries
- Extract important points from study material
- Create multiple-choice quizzes
- Check answers and show scores
- Provide explanations for answers

## Technologies Used
- Python
- Gradio
- Google Gemini API

## Installation
1. Install Python.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Create a `.env` file and add your Gemini API key:

   `GEMINI_API_KEY=your_api_key_here`

4. Run the application:

   `python app.py`

## Purpose
This project helps students understand study materials, revise important topics, and test their knowledge.
